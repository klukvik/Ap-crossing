# 📚 Ap-crossing

**Книжный шкаф буккроссинга — только для утилит, приложений и всего, чем не жалко поделиться.**

Взял полезное — оставил своё. Нашёл крутую утилиту — забрал. Сделал что-то сам или откопал классную ссылку — положил на полку, пусть пригодится другим.

---

## Идея

Буккроссинг работает просто: книга живёт не на одной полке, а переходит из рук в руки. Ap-crossing делает то же самое для софта:

- 🛠 **Утилиты и скрипты** — маленькие штуки, которые экономят время
- 📱 **Приложения** — свои и чужие, которые стоит показать
- 🔗 **Ссылки** — на репозитории, сервисы, статьи, подборки
- 📦 **Файлы** — то, что можно скачать прямо с полки
- ✨ **И всё остальное** — шаблоны, конфиги, плагины, наборы иконок, всё, чем хочется поделиться

## Как это работает

1. **Открываешь шкаф** — смотришь, что лежит на полках, ищешь по категориям и тегам.
2. **Забираешь** — одним кликом: скачать файл или перейти по ссылке.
3. **Оставляешь своё** — добавляешь утилиту, ссылку или файл с коротким описанием: что это, для чего, для какой платформы.

Никаких обязательных регистраций и барьеров там, где без них можно обойтись: главная цель — чтобы **забирать было удобно**.

## Столы

Вокруг шкафа стоят **столы**. Стол — это группа людей, объединённых одной **проблемой или запросом**. Например:

- 💸 «Переводы денег между странами»
- 🗂 «Менеджер паролей без облака»
- 🎧 «Конвертация и обработка аудио»

**Что происходит за столом:**

- **Решения с оценками и отзывами.** На столе лежат решения, которыми люди реально пользуются. Каждое можно оценить и написать, как оно сработало.
- **Разработчики приходят к столу.** Авторы могут предложить новое решение, рассказать об обновлении и получить обратную связь прямо от тех, кому оно нужно.
- **Подписка на обновления.** Кто сидит за столом, тот получает новости: появилось новое решение, вышел апдейт, поменялась оценка.
- **Можно сидеть за многими столами.** Проблем у человека обычно несколько, столов тоже может быть сколько угодно.
- **Выйти из-за стола можно, только указав «решение».** Уходя, человек говорит, что именно помогло: выбирает решение со стола или предлагает своё. Так каждый стол копит настоящий опыт, а не просто список ссылок.

**Как попасть за стол:** войти в группу может любой, кому близка эта проблема.

```
        🛠 Шкаф (все утилиты и ссылки)
              │
   ┌──────────┼──────────┐
 Стол «А»   Стол «Б»   Стол «В»
 проблема   проблема   проблема
   │           │           │
 решения    решения     решения
 + оценки   + оценки    + оценки
 + отзывы   + отзывы    + отзывы
```

## Принципы

- **Общее пространство.** У шкафа нет одного хозяина. За него отвечают все, кто им пользуется: добавляют, чистят, чинят, предлагают идеи.
- **Удобство важнее всего.** Найти и забрать нужное должно быть быстро и понятно.
- **Делимся честно.** Кладём только то, чем можно делиться: свои работы, открытые лицензии, бесплатные ресурсы. Без пиратства и вредоносного кода.
- **Описание обязательно.** У каждой вещи на полке есть пара строк: что это, зачем, откуда.
- **Уважение к авторам.** Указываем источник и лицензию.
